# Velnox Design Theme & Brand Color System

Version: 1.0
Brand: Velnox
Purpose: Professional E-commerce / Marketplace
Design Direction: Modern, trustworthy, premium, clean, technology-driven

---

## 1. Core Design Philosophy

Velnox is a professional e-commerce marketplace.

The visual identity must NOT look like:
- A cartoon website
- A playful children's product website
- An overly green website
- An organic/natural-product-only brand
- A generic template

The visual identity SHOULD feel:
- Professional
- Trustworthy
- Modern
- Clean
- Premium
- Minimal
- Technology-oriented
- Suitable for a large marketplace
- Scalable across Shop, Merchant, and Center products

IMPORTANT:

Green is Velnox's BRAND ACCENT, not the primary page color.

The website should primarily use:
- White
- Slate / neutral gray
- Dark navy-black

Green should be used selectively to create brand recognition and guide user attention.

# 5. Color Usage Ratio

Recommended visual balance:

White / Light Gray:
~80%

Dark / Slate:
~15%

Velnox Green:
~5%

The exact percentage does not need to be mathematically enforced, but the overall visual impression should follow this balance.

IMPORTANT:

The user should feel:

"Professional e-commerce platform with a green brand."

NOT:

"A green website."

Use shadows very lightly.

Preferred:

# 22. AI Implementation Rules

When another AI builds a Velnox UI, follow these rules:

1. Use the Velnox color system defined in this document.
2. Keep white and neutral colors dominant.
3. Use Velnox Green as an accent.
4. Do not turn the entire interface green.
5. Do not use green as the default background for large sections.
6. Keep cards white with subtle borders.
7. Keep primary text dark.
8. Keep body text slate gray.
9. Keep product prices dark.
10. Use amber for ratings.
11. Use semantic colors separately from brand colors.
12. Use clean spacing and strong visual hierarchy.
13. Avoid cartoon aesthetics.
14. Avoid excessive gradients.
15. Avoid excessive rounded elements.
16. Avoid excessive shadows.
17. Avoid excessive animations.
18. Keep the design suitable for a professional marketplace.
19. Preserve consistency across Velnox products.
20. If unsure, prefer minimalism and neutral colors over adding more green.

# 24. Design Decision Rule

When choosing between two designs:

Choose the design that looks:

More professional
More trustworthy
More scalable
More minimal
More readable

Even if it uses less Velnox Green.

The goal is NOT:

"Make everything Velnox Green."

The goal is:

"Make the interface recognizable as Velnox."
