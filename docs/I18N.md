# Internationalization

## Package

`packages/i18n` — Centralized translation system.

## Supported Languages

| Code | Language | Flag |
|------|----------|------|
| th | ไทย (Thai) | 🇹🇭 |
| en | English | 🇺🇸 |
| my | မြန်မာ (Burmese) | 🇲🇲 |

**Default:** th (Thai)

## Usage

```tsx
import { useI18n } from "@velnox/i18n";

function MyComponent() {
  const { t, locale, setLocale } = useI18n();
  return <h1>{t("common.welcome_message")}</h1>;
}
```

## Persistence

Locale is persisted in `localStorage` under key `velnox_locale`.
All apps share the same localStorage key.

## Adding Translations

1. Add keys to `packages/i18n/src/locales/th.json`
2. Add keys to `packages/i18n/src/locales/en.json`
3. Add keys to `packages/i18n/src/locales/my.json`
4. Use dot notation: `t("section.key_name")`

## Rules

- Do not hardcode user-facing text in reusable components
- All apps use @velnox/i18n
- Do not create separate translation systems
