# Velnox logo pack

One logo, everywhere: every file in this pack, including the favicon and the app icons, uses the same woven V. SVG is the master; PNG exports are transparent unless noted.

## What is in here

| Folder | Contents | Use it for |
|---|---|---|
| `svg/mark/` | The V mark alone: slate, white, emerald, silver | Anywhere the name is already visible nearby |
| `svg/wordmark/` | "VELNOX" alone: slate, white, emerald, emerald-dark | Footers, text-only spots, next to a separate mark |
| `svg/lockup-stacked/` | Mark above the name (6 colourways) | Square-ish spaces, covers, signage, posters |
| `svg/lockup-horizontal/` | Mark left, name right (6 colourways) | Website header, email signature, documents |
| `svg/app-icons/` | The same V on square tiles (dark, emerald, light, maskable) | App stores, home screens |
| `png/` | Transparent PNG exports of the above, plus 4 app icons (1024 px) | Slides, docs, tools that do not take SVG |
| `favicon/` | favicon.ico, favicon.svg, apple-touch-icon, 192/512 icons, maskable icon, manifest, `<head>` snippet | The website |
| `social/` | OG image 1200x630, banner 1500x500, avatar 1080, wallpaper 1920x1080 | Link previews, profiles, covers |
| `guidelines/` | Brand guidelines (md) and a one-page brand sheet (png) | Rules for using the logo |

## Which colourway?

- `light` — dark mark + dark-green name, for white or light backgrounds
- `dark` — silver mark + emerald name, for dark backgrounds (the hero version)
- `white` — all white, for photos or coloured backgrounds
- `white-emerald` — white mark + emerald name, for dark backgrounds without the gradient
- `mono` — one dark colour, for one-colour print and stamps
- `emerald` — all emerald, for single-colour brand moments

## Website quick start

Copy everything in `favicon/` to your site root and paste `favicon/head-snippet.html` into `<head>`.
